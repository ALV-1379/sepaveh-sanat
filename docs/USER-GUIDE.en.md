# Sepaveh Sanat Naghsh Jahan user guide

## Visitors and customers

1. Open the website in your browser. Use the فارسی or English radio button at the top to change language.
2. Open **Products**, search for equipment, and select a product to see its photos and description. Use **Download catalog (PDF)** to save the company catalog.
3. Choose **Request a quotation**. Enter your name, phone number, delivery or installation address, and a description of what you need. Include quantities, dimensions, or required capacity if you know them.
4. Choose Eitaa, Telegram, WhatsApp, or phone call. Use a number the sales team can reach through that channel. Submit and wait for the confirmation. The sales team follows up manually.
5. Use **Contact** for a general question. Visitors can browse and submit requests without creating an account.

## Content administrators

1. Open `/admin` on the same website and sign in with the credentials provided by your super admin. The panel is in Persian.
2. Open **پیام‌ها و درخواست‌ها** to review inquiries. A quotation shows the phone, address, requested work, and preferred channel. Follow up using that channel and mark the message as read when reviewed.
3. Use **محصولات**, **پروژه‌ها**, or **صفحات** to edit content. Save the draft, preview it, then publish it when ready. Update the Persian and English entries separately.
4. Use **کتابخانه رسانه** to upload images and PDFs. Mark a file public if it belongs on a public page. Keep customer information out of public uploads.

## Super administrators

1. Open `/super-admin` and sign in with your super admin account.
2. In **مدیران**, create accounts and select either **مدیر محتوا** for content work or **مدیر ارشد** for system administration. Disable accounts when access is no longer needed.
3. Check **گزارش فعالیت** for changes, **سلامت سامانه** for service status, and **آمار بازدید** for site traffic.

If you were given a website link, open it directly. For a local Windows installation, use the [setup instructions](../README.md#windows-and-wsl2).
